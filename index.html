🌐 What is HTML?

HTML stands for HyperText Markup Language.

HTML is the standard markup language used to create the structure and content of web pages.

It tells a web browser what different parts of a webpage are, such as headings, paragraphs, images, links, lists, tables and forms.

HTML is not a programming language. It is a markup language.

⚙️ How Does HTML Work?

HTML works by using elements and tags. The developer writes HTML code inside an HTML file, usually with the extension .html.

The web browser reads this HTML code and converts it into the webpage that we see.

👩‍💻 Write HTML → 📄 HTML File → 🌐 Browser → 🖥️ Web Page

HTML provides many elements that allow developers to create the structure and content of websites.

🧱 Page Structure

HTML provides the basic structure of a webpage using elements such as html, head and body.

📝 Text Content

HTML allows developers to create headings, paragraphs and different types of text.

🔗 Hyperlinks

HTML allows users to move between webpages using hyperlinks.

🖼️ Images

HTML provides the image element for displaying pictures on webpages.

📋 Lists

HTML supports ordered and unordered lists for organizing information.

📊 Tables

HTML tables are used to display information in rows and columns.

📝 Forms

HTML forms allow users to enter information such as names, emails and passwords.

🎵 Multimedia

HTML supports multimedia elements such as audio and video.

🧩 Semantic HTML

🔑 Attributes

🏗️ Basic Structure of an HTML5 Document

Every HTML document normally starts with a basic structure. The main parts are explained below. 

<!DOCTYPE html>

<html>

    <head>

        <title>My Web Page</title>

    </head>

    <body>

        <h1>Hello World</h1>

        <p>This is my webpage.</p>

    </body>

</html>

DOCTYPE

<!DOCTYPE html> tells the browser that the document uses HTML5.

HTML Element

<html> is the root element of an HTML document.

Head

<head> contains information about the webpage, such as its title and metadata.

Body

<body> contains the visible content of the webpage.

🏷️ HTML Tags and Elements

HTML uses tags to define different types of content. A complete HTML element can contain an opening tag, content and a closing tag. 

<p>This is a paragraph.</p>

Here <p> is the opening tag, the text is the content, and </p> is the closing tag.

📚 Common HTML Elements

Element Purpose
<h1> - <h6> Creates headings
<p> Creates paragraphs
<a> Creates hyperlinks
<img> Displays images
<ul> Creates unordered lists
<ol> Creates ordered lists
<table> Creates tables
<form> Creates forms
<audio> Embeds audio
<video> Embeds video

🔑 HTML Attributes

Attributes provide additional information about an HTML element.

They are written inside the opening tag. 

<a href="https://example.com">
    Visit Website
</a>

Here href is an attribute that specifies the destination of the link.

🧩 Semantic HTML

Semantic HTML uses meaningful elements to describe the purpose of different sections of a webpage.

Element Meaning
<header> Page or section header
<nav> Navigation links
<main> Main content
<section> A section of content
<article> Independent content
<footer> Footer of a page or section
